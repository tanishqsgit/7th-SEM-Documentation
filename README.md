### Project overview

AgentOps combines a TypeScript and Node.js backend, a SQLite-backed message queue, provider command-line adapters, agent teams, persistent Markdown memory, scheduling, and a separate web dashboard. The documented channels include Telegram, WhatsApp, Discord, and a command-line interface.

The current documented implementation runs on one host and can be deployed on a suitable cloud virtual machine. Distributed execution across multiple hosts remains future work.
