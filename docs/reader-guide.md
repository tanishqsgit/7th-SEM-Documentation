# Find the right AgentOps document

This repository holds academic documentation for a multi-agent orchestration
project. It does not include the runnable product source.

## Choose a reading path

| Your goal | Start here | What you can assess |
| --- | --- | --- |
| Understand the system | [Project documentation](../project-documentation/PROJECT_DOCUMENTATION.md) | Architecture, components, interfaces, and constraints |
| Review the research framing | [Editable manuscript](../research-paper/AgentOps_Research_Paper_Editable.md) | Problem statement, approach, and proposed evaluation |
| Find report downloads | [Document index](../README.md) | Word and PDF report links |

For a short first pass, read the architecture, message-flow, security, and
limitations sections in the project documentation before the detailed interfaces.

## Check claims before reuse

The current README describes a single-host implementation. Multi-host distributed
execution remains future work. The manuscript is unpublished. Proposed evaluation
procedures should not be read as measured results.

Setup commands and API descriptions in the academic report need comparison with
the corresponding source version before being used as product instructions.
No runnable source or independent product verification was added in this update.

## Review a procedure

1. Identify the source revision, intended user, and one task outcome.
2. Confirm prerequisites and commands against that source revision.
3. Execute each step in a disposable environment and record actual output.
4. Correct discrepancies and mark untested behavior explicitly.
5. Request review from the project team before publishing a verified procedure.

Personal authorship and team contributions need confirmation from the contributors.
The presence of a document in this team repository does not establish sole authorship.
